1、第一个就是应该尽量避免全表扫描，首先考虑考虑在 where 和 order by 涉及的列上建立索引

```
create index index_name on table_name(column_name)

ALTER table table_name ADD INDEX index_name(column_name)
```

2、索引虽然可以提高查询效率，但给一个表建立太多索引也不好，索引也会降低 insert，update  和 delete 的效率。（因为每次都要重建索引的）

3、尽量避免在 where 子句中的一些操作：

如：1）、判断 null ，这样会导致引擎放弃使用索引而进行全表扫描

​	   2）、使用 or 连接条件，同上

​	   3）、尽量不要使用表达式，同上

​	   4）、尽量使用 between 而不是 in

4、少使用 * ，要什么查询什么。
