##### 一、为MySQL表添加外键

建数据库时，先建表，建完表再添加主键外键。

```mysql
例：
create table class(
    id int primary key,
    cname varchar(20),
    cdesc varchar(50)
);
create table students(
    sid int primary key,
    ssex char(2),
    sname varchar(20),
    cid int
);

# 为student表的 cid 列添加外键关系，并将这个约束命名为fk_student_gid
# 为某一个列添加外键关系
alter table students add foreign key (cid) references class(id)
# 删除外键关系
ALTER TABLE students DROP FOREIGN KEY fk_student_gid


# 为多个列添加外键关系
alter table students
add constraint foreign_key1 foreign key (column1) references class(id)
add constraint foreign_key1 foreign key (column2) references class(id);
on delete cascade;

# 外键约束有 on update 和 on delete 表示更新和删除时怎么做
# 两者都包括以下四种选项：
# 1、cascade：级联，当主表更新、删除，从表会同步更新和删除
# 2、set null：置空，当主表更新、删除的时候，从表会把外键字段变为null，所以这个时候设计表的时候该字段要允许为null，否则会出错。
# 3、restrict：主表在删除和更新记录的时候，要在从表中检查是否有 有关该主表要更新和删除的记录，如果有，则不允许删除个更改
# 4、同restrict
```

**列级约束：**

1. 主键(PRIMARY KEY)
2. 外键(FOREIGN KEY)
3. 唯一(UNIQUE)
4. 检查(CHECK)
5. 默认(DEFAULT)
6. 空/非空值(NULL/NOT NULL)

**表级约束：**主键，外键，唯一，检查。（同时对表中的两个或两个以上的列增加约束条件。）
