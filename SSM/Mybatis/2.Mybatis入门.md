#### 1、Mybatis入门：

（Idea对应项目名称：**MybatisDemo**）

Mybatis官网：https://mybatis.org/mybatis-3/zh/index.html

Mybatis的环境搭建：

​	1、创建maven工程并导入相关坐标

​	2、创建实体类和dao的接口

​	3、创建Mybatis的主配置文件 SqlMapConfig.xml

​	4、创建dao接口对应的映射配置文件

环境搭建时的注意事项：

​	1、接口对应的配置文件 叫 IUserDao.xml 或者 IUserMapper.xml 都可以，看个人喜好。

​	2、Mybatis的xml配置文件包结构，必须和dao接口包结构完全一致。

​	3、映射配置文件最外层 mapper标签的 namespace 属性，取值必须是对应dao接口的全限定类名。

#### 2、Mybatis中的设计模式

（1）建造者模式

```
inputStream = Resources.getResourceAsStream("SqlMapConfig.xml");
SqlSessionFactory sqlSessionFactory = new SqlSessionFactoryBuilder().build(inputStream);
//SqlSessionFactory 的工厂 SqlSessionFactoryBuilder，用build方法创建
//优势：隐藏了对象创建细节，使用者直接调用创建方法即可拿到对象
```

（2）工厂模式

```
sqlSession = sqlSessionFactory.openSession();
//不用new关键字，使用工厂为我们生产一个对象。
//优势：解耦，降低依赖关系
```

（3）代理者模式

```
accountDao = sqlSession.getMapper(IAccountDao.class); 
//创建了Dao接口的代理对象
//优势：在不修改源码的基础上对已有的方法增强

```
