### 编译期常量与运行时常量

在 Java 中，用关键字 `static final` 修饰的常量分为：

- 编译期常量

- 运行时常量

单独用 `final` 修饰的变量，表示不可变的实例变量，没什么需要讨论的不再赘述。

#### 编译期常量

```java
static final int staticFianl = 47;
```

编译期常量，在编译阶段就会把值存入其调用类的常量池中。我们在获取其值的时候，并不需要直接引用到其调用类，所以就不会触发类的初始化。总结就是，**编译期常量不依赖类，不会引起类的初始化**。

#### 运行时常量

```java
static final int staticFianl2 = ClassInitialization.rand.nextInt(1000);		//这里叫：非常数静态域
```

运行时常量，运行时才可以确定其值，所以**运行时常量依赖类，会引起类的初始化**。
