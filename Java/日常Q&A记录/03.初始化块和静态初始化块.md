### 初始化块，静态初始化块，构造器

​	初始化化块和初始化器指的都一个东西 (Initializer block)，均指：定义在类中，用大括号 {...} 括起来的代码块。除此之外，静态初始化块还要在大括号前加上 static 关键字。

#### 初始化块

​	初始化块，即非静态初始化块，普通初始化块。

​	Java 用构造器对单个对象进行初始化，我们使用构造器可以对 java 对象进行更加详细的初始化。与构造器作用非常类似的就是 (普通) 初始化块了，它也可以对 java 对象进行初始化操作。

```java
import java.util.*;

class Parent{
    {
        System.out.println("父类普通初始化块");
    }
    Parent(){
        System.out.println("父类无参构造器");
    }
}

public class Main  extends Parent {

    {
        //初始化块里的代码可以包含任何可执行的语句，包括定义局部变量，调用其他方法，使用分支，循环语句等。
        int var = new Random().nextInt();
        if (var > 29)
            System.out.println("普通初始化块1，随机到了大于29的数");
        System.out.println("普通初始化块1");
    }

    {
        System.out.println("普通初始化块2");
    }

    Main() {
        System.out.println("无参构造器");
    }
    public static void main(String[] args) {
        new Main();
    }
}
```

运行结果如下：

```
父类普通初始化块
父类无参构造器
普通初始化块1
普通初始化块2
无参构造器
```

结论分析：创建 java 对象时，先执行初始化块，然后执行构造方法；如果有多个初始化块，则按照顺序执行多个初始化块。（注意不管是静不静态的初始化块，创建对象触发类初始化的时候，都会先初始化父类！！！）

- **普通初始化块的作用：**给对象进行初始化。对象一创建就运行，且优先于构造器运行。
- **与构造器的区别：**初始化块给所有对象进行统一初始化，而构造器只给对应的对象初始化。
- **普通初始化块的应用：**将所有构造器共性的代码提取出来写在普通初始化块中。

#### 静态初始化块

​	静态初始化块，即用 static 修饰的初始化块，也叫类初始化块。

​	由于类初始化的机制：假如初始化类的父类未初始化，则要先初始化其父类！而静态初始化块和静态变量一样，是属于类的！所以它们和类是一起初始化的，是类加载时候自动完成的。但是普通初始化块和构造器并不是属于类的，所以类初始化的时候并不会执行它们！

​	看示例代码：

```java
class Top {
    static {
        System.out.println("Top的——静态初始化块");
    }
    {
        System.out.println("Top的——普通初始化块");
    }
    public Top() {
        System.out.println("Top的无参构造函数");
    }
}

class Mid extends Top{
    static {
        System.out.println("Mid的——静态初始化块");
    }
    {
        System.out.println("Mid的——普通初始化块");
    }
    public Mid() {
        System.out.println("Mid的无参构造函数");
    }
}

class Bottom extends Mid{
    static {
        System.out.println("Bottom的——静态初始化块");
    }
    {
        System.out.println("Bottom的——普通初始化块");
    }
    public Bottom() {
        System.out.println("Bottom的无参构造函数");
    }
}

public class Main extends Bottom{
    public static void main(String[] args) {
        System.out.println("==========第一次创建对象==========");
        new Bottom();
        System.out.println("==========第二次创建对象==========");
        new Bottom();
    }
}
```

运行结果：

```
Top的——静态初始化块
Mid的——静态初始化块
Bottom的——静态初始化块
==========第一次创建对象==========
Top的——普通初始化块
Top的无参构造函数
Mid的——普通初始化块
Mid的无参构造函数
Bottom的——普通初始化块
Bottom的无参构造函数
==========第二次创建对象==========
Top的——普通初始化块
Top的无参构造函数
Mid的——普通初始化块
Mid的无参构造函数
Bottom的——普通初始化块
Bottom的无参构造函数
```

结论分析：结合 JVM 类初始化的机制，我们知道初始化Main的时候，会先从继承链最顶层一路初始化下来。而静态初始化块是类的，随类初始化执行。**且在初始化时仅执行一次**。然后就是按照继承链 —— 父子孙的顺序，先执行父类里的普通初始化块，构造函数，接着子类里的普通初始化块，构造函数... ...
