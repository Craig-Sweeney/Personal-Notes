#### 一、多线程的原理：

​	同一时间，CPU是只能处理一条线程，多线程并发执行，其实是CPU在多个线程之前快速调度，看起来像是多个线程在同时执行。这就造成了多线程并发执行的假象。
​	多个线程并发执行能提高程序的执行效率，适当提高资源（CPU、内存）利用率。现在也是多核CPU，并发也能避免CPU资源的浪费。但多线程并发也会带来安全性问题：
​	在同一个程序中，运行多个线程并不会导致问题，但是当多个线程都要访问相同的资源，就会出现安全性问题。实际上，这些问题只有在一或多个线程向这些资源做了写操作时才有可能发生，只要资源没有发生变化,多个线程读取相同的资源就是安全的。

#### 二、竞态条件与临界区

​	当多个线程需要访问同一个资源的时候，并且对访问顺序敏感，那么就称存在竞态条件。**临界区**指的是一个访问共用资源的程序片段。

​	当一个线程执行到临界区的时候，其他线程必须等待，以确保这些共用资源是互斥使用的。为了避免多个线程同时访问一个资源，可以使用synchronized关键字，给临界区加锁，使得临界区同一时间只允许一个线程执行，实现互斥。

#### 三、线程的六种状态

- 初始状态(NEW)
- 运行状态(Runnable)
- 阻塞状态(Block)
- 等待状态(Waiting)
- 计时等待状态(Timed Waiting)
- 终止状态(Terminated)

#### 四、Java 线程的创建方式

1、继承 Thread 类

Thread 类本质上是实现了 Runnable 接口的一个实例，代表一个线程的实例。启动线程的唯一方法就是通过 Thread 类的 start() 实例方法。start() 方法是一个 native(本地) 方法，它将启动一个新线程，并执行 run() 方法。

```java
public class MyThread extends Thread {
    public void run(){
        System.out.println("my thread is running");
    }
}
MyThread my = new MyThread();
my.start();
```

2、实现 Runnable 接口

​	推荐使用，因为继承是单继承，但是接口是多实现。假如自己的类已经 extends 了其他类，就无法再继承 Thread 类了，所以可以实现 Runnable 接口。

```java
public class MyThread extends OtherClass implements Runnable {
	public void run() {			//线程任务就是 run 方法
		System.out.println("MyThread.run()");
	}
}
//启动 MyThread，需要首先实例化一个 Thread，并传入自己的 MyThread 实例：
MyThread myThread = new MyThread();		//线程任务
Thread thread = new Thread(myThread);		//线程
thread.start();
//因此，这种方式实现了 线程 和 线程任务 的分离。
```

3、Callable

​	有返回值的任务必须实现 Callable 接口，类似的，无返回值的任务必须 Runnable 接口。执行Callable 任务后，可以获取一个 Future 的对象，在该对象上调用 get 就可以获取到 Callable 任务返回的 Object 了。

4.线程池

​	线程和数据库连接这些资源都是非常宝贵的资源。那么每次需要的时候创建，不需要的时候销毁，是非常浪费资源的。那么我们就可以使用缓存的策略，也就是使用线程池。
