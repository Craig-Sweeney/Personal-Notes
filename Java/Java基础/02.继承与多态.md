### 继承

​	继承有什么意义呢？
​	继承的子类是对父类的改进与扩充，所以一般的子类在功能上较父类更为强大，属性较父类更为独特。定义一个父类类型的引用指向一个子类对象，既可以使用子类强大的功能，又可以抽取父类的共性。

### 多态存在的三个必要条件

1. **继承**
2. **覆盖 override**
3. **父类引用指向子类对象**

​    父类型的引用只能调用父类中定义的所有属性和方法，而对于子类中定义而父类没有的方法，它是无可奈何的。

​    同时，父类引用所调用的父类方法中，在子类中一定是没有重写的！

​    如果该方法在子类中重写了，那么父类型的引用将会调用子类中重写过的方法！这也就是动态绑定（既运行时绑定，或后期绑定）

多态分两种：

1、编译时多态（设计时多态）：方法重载
2、上文所讲的运行时多态：动态绑定

### super关键字

1. 子类可以继承父类所有可访问的数据域和方法，但是不能继承构造方法。
2. super指这个super出现的类的父类。super关键字的两种使用途径：
   - 调用父类的构造方法
   - 调用父类的方法（因为动态绑定的缘故，使用super强制调用）
3. 构造方法链
   如果要调用父类的构造方法，则必须将super() 或 super(参数) 放在构造器的第一行显示调用。
   若没有明显的显示调用，则编译器会自动的将super()作为构造方法第一条语句。
   在任何情况下构造一个类的实例时，都会沿着继承链不断地向上调用父类的构造方法，直到这个继承体系结构的最后一个构造方法被调用为止。这就是构造方法链。

### this关键字

1. 代指。哪个实例使用，哪个实例就是this。注意用this可以不用new一个实例，如：类名.this.XXX
2. 在无参构造器或者参数较少的构造器中使用 this(参数列表) 调用参数多的构造器。
