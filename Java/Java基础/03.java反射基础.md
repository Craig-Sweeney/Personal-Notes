### 关于对象

在java中，所有的东西都是对象，除了两样东西：

1、静态成员：静态成员不是对象，这是属于类的

2、基本数据类型：如 int，double

即使是类，也是对象，所有的类都是java.lang.Class类的实例对象。



### 表示Class类的实例对象：

```java
//我们用Foo代表一个普遍的类
一般类的实例对象如何表示 Foo foo = new Foo();
但是任何一个类都是Class类的实例对象，Class类的实例对象怎么表示呢？
对于任何一个类，既Class类的实例对象，这里有三种表示方法：
//可以查看Class类的构造函数声明为private，是私有的，我们是不能new的。
1) Class c1 = Foo.class
    //第一种表示方法实际是在告诉我们任何一个类都有一个隐含的静态成员变量class
2) Class c2 = foo.getClass();
    //第二种表达方式，已经知道了该类的一个对象，通过getClass方法
3) Class c3 = null;
    c3 = Class.forName("类的位置，要绝对路径")；
    //第三种方式会抛出异常，ClassNotFoundException异常。

根据java官网的说明：c1, c2 表示了Foo类的类类型(class type)，也就是说我们把Class类的实例对象也称作某一个类的类类型。
那么c1 == c2吗？答案是true，c1 == c2 比较了两个对象的地址，而一个类就是Class的一个对象，那么c1, c2 就是同一个Class的对象。

所以现在我们可以获得Foo类的类类型c1 or c2 or c3, 那么我们完全可以通过类的类类型来创建该类的对象实例。
//会抛出异常
Foo foo = (Foo)c1.newInstance();  //需要Foo类有无参的构造方法
```
