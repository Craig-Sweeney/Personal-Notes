### 抽象类

1. 含抽象方法的类 必为 抽象类。但可以定义一个不包含抽象方法的抽象类。
2. 抽象类一般是作为父类被子类继承的，但它也可以作为一个具体类的子类。如：object类为具体类，但所有类都是它的子类（包括抽象类）。
3. 如果抽象类的子类不能实现 所有 的抽象方法，那么子类也必须定义为抽象类。换句话说，**在抽象类扩展的非抽象子类中，子类必须实现所有的抽象方法。**
4. 请将抽象类的构造方法定义为protected，因为它只被子类使用。
5. 抽象类不能使用 new 来构造实例对象，但是可以定义对象引用，作为父类型引用指向子类对象。所以可以用抽象类型构建数组（一组未赋对象的引用），再构造实例赋给数组元素。

### 接口

​	※ 接口只包含常量与抽象方法

​	在java中，类是单继承的，而接口是多继承的。既 一个类可以实现多个接口！

​	注意：在接口中，所有常量都是 **public final static** ; 所有方法都是 **public abstract** , 所以在接口类中，默认可以省略这些修饰符。
