#### 查看远程仓库

```
git remote
```

​	如果你已经克隆了自己的仓库，运行 `git remote` 命令，那么至少应该能看到 origin 。
​	**origin 是 Git 给远程仓库的默认名字！**

```
git remote -v			// v 指 verbose，形容词，冗长的，啰嗦的
```

​	选项 `-v`，会显示需要 **读写** 远程仓库的简称与其对应的 URL

```
$ git remote -v
origin	https://github.com/schacon/ticgit (fetch)		//拥有origin远程仓库的拉取权限
origin	https://github.com/schacon/ticgit (push)		//拥有origin远程仓库的推送权限
```

#### 添加远程仓库

```
git remote add <shortname> <url>
$ git remote add pb https://github.com/paulboone/ticgit
$ git remote
orgin
pb
```

#### 从远程仓库中拉取数据

```
git fetch <remote>
//例如，如果你想拉取 Paul 的仓库中有但你没有的信息，可以运行：
$ git fetch pb
```

（请详细阅读以下两段，每句都是重点！！）
	如果你使用 `clone` 命令克隆了一个仓库，命令会自动将其添加为远程仓库并默认简称为 “origin” 。 所以，`git fetch origin` 会抓取 克隆（**或上一次抓取**）后 **新推送的所有工作**。 必须注意 `git fetch` 命令只会将数据下载到你的本地仓库——它并不会自动合并或修改你当前的工作。 当准备好时你必须手动将其合并入你的工作。

​	如果你的当前分支设置了跟踪远程分支， 那么可以用 `git pull` 命令来自动 **抓取** 后 **合并** 该远程分支到当前分支。 这或许是个更加简单舒服的工作流程。默认情况下，`git clone` 命令会自动设置本地 master 分支跟踪 克隆的远程仓库的 `master` 分支（或其它名字的默认分支）。 运行 `git pull` 通常会从最初克隆的服务器上抓取数据并自动尝试合并到当前所在的分支。

####  向远程仓库推送数据

```
git push <remote> <branch>
//例如，如果你想推送到默认远程仓库origin的主分支master
$ git push origin master
```

（请详细阅读以下一段，每句都是重点！！）
	只有当你有所克隆服务器的写入权限，并且之前没有人推送过时，这条命令才能生效。 当你和其他人在同一时间克隆，他们先推送到上游然后你再推送到上游，你的推送就会毫无疑问地被拒绝。 你必须先抓取他们的工作并将其合并进你的工作后才能推送。

#### 查看某个远程仓库

```
git remote show <remote>
//例如查看origin
$ git remote show origin
* remote origin
  Fetch URL: https://github.com/schacon/ticgit
  Push  URL: https://github.com/schacon/ticgit
  HEAD branch: master		//告诉你正处于当前远程仓库的master分支
  Remote branches:			//告诉你当前远程仓库都有哪些分支
    master                               tracked
    dev-branch                           tracked
  Local branch configured for 'git pull':	//pull拉取的是哪个分支
    master merges with remote master
  Local ref configured for 'git push':		//push推送的是那个分支
    master pushes to master (up to date)
```

#### 远程仓库的重命名

```
git remote rename
//例如将pb重命名为paul
$ git remote rename pb paul
$ git remote
origin
paul
```

#### 远程仓库的移除

```
git remote remove 或 git remote rm
//例如移除远程仓库paul
$ git remote rm paul
$ git remote
origin
```
