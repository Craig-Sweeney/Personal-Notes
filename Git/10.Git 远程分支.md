#### 远程分支

```
git remote					//查看所有的远程仓库
```

```
git ls-remote <remote>		 //查看当前远程仓库的分支
$ git ls-remote origin
83e3f9662dc6e22065db3bf8c9393bc16cdfcb75        HEAD
83e3f9662dc6e22065db3bf8c9393bc16cdfcb75        refs/heads/master
```

```
git remote show <remote>	 //查看当前远程仓库详细信息，详见笔记06.远程仓库的使用
```
