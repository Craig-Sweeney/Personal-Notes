### GitHub的安装

​	首先Mac系统自带Git。

​	windows要安装Git。安装完成有git-bash可供使用。另外windows下还有TortoiseGit第三方软件（类似用过的TortoiseSVN）。

​	所有系统都可以用GitHub网站自己的软件：GitHub Desktop。

### Mac终端的优化

​	Mac从Catalina版本开始就不适用以前的bash了，使用的是zsh。但zsh不够强大，可以下载GitHub开源项目oh my zsh。

其官方网址为：https://github.com/ohmyzsh/ohmyzsh#using-oh-my-zsh

​	使用curl下载安装oh my zsh时，由于Mac自带的hosts文件中GitHub网址对应的ip地址有误，导致报错证书不匹配，下载失败。查询GitHub各个网址对应的正确ip，并修改hosts文件，即可正常下载。

curl 安装命令：

```
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

### SSH

​	SSH 是secure shell的缩写，SSH是一种协议，一种专门为远程登录会话和其他网络服务提供的安全性协议。

​	SSH 密钥分 公钥 和 私钥。私钥自留，公钥可以给其他人。所有的key默认存在.ssh文件夹中，文件夹除了私钥和带pub后缀的公钥，还有一个known_hosts文件记录曾经访问过的服务器电脑。

​	1、检查之前自己有没有生成过SSH key

```
ls -al ~/.ssh            #ssh key统一放在 ~根目录名为 .ssh 的隐藏文件夹中
```

​	2、如果有，则直接使用以前的即可。

​		如果没有，则先检查下自己有没有配置：

```
git config user.name
git config user.email
```

​		如果没有配置，则执行以下命令配置：

```
git config –global user.name ‘xxxxx’ 
git config –global user.email ‘xxx@xx.com’
```

​		最后，生成密钥：

```
ssh-keygen -t rsa -C ‘上面的邮箱’
```

参数含义：

​		-t : 既type，指定加密算法类型，默认rsa。还有一种是dsa。

​		-C : 既comment，设置注释文字。可以不写

​		-f : 既file，指定密钥文件存储的文件名。不指定，用默认的，不写。

​		最最后，连按三次回车：
