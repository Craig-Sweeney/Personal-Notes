一、GitHub中New Repository和New Project的区别

​	Repository就是存放代码的仓库，可以保存任意多个代码工程，包括其中的资源文件，图片，文本等信息。

​	Project 其实全称为 Project-Boards：项目板。官方解释：You can track and prioritize your work on GitHub by creating a project board with associated issues, pull requests, and notes.

二、关联本地仓库与远程仓库。

​	在GitHub网站建立一个新的仓库，如何与本地仓库之间交互？就要用Git的远程操作命令。

```
#从本地到远程
git init
git add README.md
git commit -m "first commit"
git remote add origin <hhtps or ssh url>
git push -u origin master

#从远程到本地
git clone <url>					//克隆远程仓库
git fetch <remote>				//从远程仓库获取代码
git pull <remote> <branch>		 //下载代码并快速合并(pull=fetch+merge)
```



三、帮助

```
git help <command>
git help push   //帮助会给出该命令可用参数及参数意义
=====================================================
git <command> --help
git add --help  //全面详细的手册
git add -h   	//简明解释
```
