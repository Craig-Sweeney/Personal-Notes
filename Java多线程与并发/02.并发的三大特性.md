### 三大特性：原子性，可见性，有序性

### Java 的内存模型

​	JDK1.2 之前，Java 的内存模型实现总是从主存（共享内存）中读取变量，这是不需要进行特别注意的。但从内存中读取数据和向内存中写入数据的过程，跟CPU执行指令的过程比起来是慢很多的。因为每次都和内存交互势必会大大降低指令的执行速度。所以现在的 Java 内存模型还包括了 CPU 寄存器，高速缓存等。这就可能造成一个线程在主存中修改了共享变量，而另一个线程还在继续使用寄存器中共享变量的拷贝值，造成数据的不一致。

要解决这个问题：

1. ​	把共享变量声明为 volatile 。告诉 JVM 这个变量是不稳定的，每次使用它都要从主存中获取。
2. ​	加锁

### 一、原子性

​	既一个操作和多个操作，要么全部执行并且执行过程不会中断，要么都不执行。

### 二、可见性

​	指当多个线程访问同一个变量时，一个线程修改了这个变量的值，其他线程能够立即看到修改的值。

### 三、有序性

​	处理器为了提高程序的运行效率，可能会进行指令重排序。指令重排序虽然会使得 CPU 执行各语句的顺序 可能和 写的代码顺序并不一致。但是它会保证最终执行结果和代码顺序执行结果一致。（指令重排序会考虑各个语句之间的数据依赖性，互不相干的语句可能会发生指令重排序。）

​	单线程，指令重排序不会出问题，但是在多线程环境下，指令重排序就可能会导致程序出错。
