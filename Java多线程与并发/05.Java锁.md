### 一、乐观锁

​	乐观锁是一种乐观思想，认为总是读多写少。遇到并发写的可能性低，每次去拿数据的时候都认为别人不会修改，所以不上锁。但是在更新数据的时候，会判一下在此期间有没有别人去更新过这个数据。

​	Java 中的乐观锁基本都是通过 CAS 操作实现的，CAS 更新是一种原子性操作，compare and swap。比较（相同）则更换。

### 二、悲观锁

​	悲观锁就是悲观思想，认为写多读少。遇到并发写的可能性高，每次拿数据都认为别人会修改，所以每次读写数据都会上锁。

​	Java中 的悲观锁就是 synchronized。（synchronized 就死同步锁：保证线程 同步互斥）

### 三、自旋锁

​	一个线程来了的时候，资源正在被另一个线程持有。但持有锁的线程可能很快就执行完了，如果让这个竞争资源的线程切换状态（阻塞），反而更浪费时间，不如只让它们等一等（自旋），等持有锁线程很快释放资源后就可以获取锁了。这样能避免比较重量级的状态切换。

### 四、死锁

​	死锁就是多个线程同时被阻塞，它们中的一个或者全部都在等待某个资源被释放
